# Premium frontend routing

Use this path for a landing page, dashboard, admin panel or SaaS interface.

1. Select one art-direction skill (`frontend-design-pipeline`, `design-taste-frontend` or `ui-ux-pro-max`) to establish one intentional visual direction before implementation.
2. Select one implementation skill (`shadcn`, `tailwind-design-system` or `vercel-composition-patterns`) when its technology applies.
3. Select one validation skill (`impeccable`, `accessibility` or `performance`). Do not activate more than three skills total.
4. Preserve responsive behavior, accessibility and Core Web Vitals. After implementation, use the approved browser/QA workflow to capture desktop and mobile screenshots, inspect visible defects, correct them and rerun the relevant checks.
5. Record evidence through the existing QA and milestone process; this routing adds no competing release gate.

The canonical trigger and candidate list lives in `skills-routing.yaml` under `premium_frontend`.
