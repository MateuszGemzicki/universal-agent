# Roadmap

1. **Foundation (included)**: CLI, multi-repo registry, SHA-256 tree, incremental Python inventory, SQLite audit, test command.
2. **Polyglot parsing**: tree-sitter or language servers for TS/JS/Go/C#/Java etc.; symbol-level structural hashes; cross-repo dependency resolution.
3. **Knowledge compilation**: graph tables, document generators, evidence and provenance, dependency-aware invalidation.
4. **LLM orchestration**: provider adapters (Codex/Claude/Gemini), versioned prompts, role-specific context retrieval, task queue and approval UX.
5. **TDD automation**: test generation, red/green verification, coverage and mutation testing, CI isolation, bounded retries.
6. **Browser service**: shared Playwright browser, recorded routes, locator repair and visual evidence.
7. **Self-improvement**: versioned skills, candidate CMD scripts, explicit approval gates, outcome scoring and rollback.
8. **Production hardening**: auth, RBAC, secret vault, sandboxing, rate/cost limits, telemetry, Postgres migrations and backup.

Do not assume static call graphs fully describe reflection, dynamic dispatch or distributed events. Use runtime evidence and confidence labels.
